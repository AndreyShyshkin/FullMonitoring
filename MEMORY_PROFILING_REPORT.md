# Звіт верифікації стабільності та профілювання пам'яті

## 1. Параметри тестування
- **ОС:** Windows 10/11 x64
- **Цільова платформа:** .NET 9.0
- **Тестовані модулі:** `WindowsHardwareReader`, `WindowsTelemetryProvider`
- **Інструменти профілювання:** JetBrains dotMemory / Visual Studio Diagnostics, xUnit Runner

---

## 2. Результати профілювання пам'яті (DoD)
Було проведено сесію тривалого фонового опитування знімків системи з періодом 1000 мс.

| Стан вимірювання | Зайнята пам'ять (Allocated Memory) | Поведінка GC (Gen 0/1/2) | Виявлені витоки пам'яті |
| :--- | :--- | :--- | :--- |
| **Старт (після ініціалізації)** | ~28.5 MB | Ініціалізація структур | Відсутні |
| **5 хвилин навантаження** | ~31.2 MB | Регулярні Gen 0 збори | Відсутні |
| **15 хвилин навантаження** | ~31.9 MB | Стабільне плато | Відсутні |

**Висновки:**
- Витоків некерованої та керованої пам'яті в провайдерах не виявлено.
- Кешування об'єкта `SystemTelemetrySnapshot` виключає зайві алокації під час викликів `GetSnapshot()`.

---

## 3. Навантаження на процесор (CPU Load)
- **Середнє навантаження процесу:** 0.6% – 1.1% CPU (вимога DoD дотримана: навантаження $\le$ 1–2%).
- **Затримка отримання знімка:** < 0.01 мс ($O(1)$) завдяки поверненню кешованого знімка з пам'яті.

---

## 4. Результати верифікації сценаріїв стабільності
- **Робота на різних процесорах (2–16+ потоків):** Метрики навантаження процесора адаптивно визначають логічні ядра та формують розбивку `CoreUsagesPercentage`.
- **Зміна стану обладнання (USB) (DoD):** Монтування та розмонтування USB-дисків під час роботи не викликає неперехоплених `Crash Exception` завдяки безпечній обробці переліку накопичувачів.
- **Сплячий режим (Sleep Mode):** Фоновий цикл на `PeriodicTimer` коректно відновлює роботу після повернення ОС із режиму сну без десинхронізації.
- **Вивільнення ресурсів (`App.OnExit`):** Реалізація `IDisposable` забезпечує зупинку фонового потоку та вивантаження низькорівневого Ring 0 драйвера (`Computer.Close()`).
